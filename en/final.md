## Contest Procedures

It will be held offline.

- Account information for the contest will be distributed to participating teams on the day of the contest. You can log in with this account on the contest day to conduct system tests.
- Each team can use a maximum of one computer, one monitor, one mouse, and one keyboard.
  - The computer must be brought by the team.
- Each team may refer to a team reference document of up to 25 single-sided A4 pages. Please refer to below for formatting and restrictions.
- Participating teams may request to print their code. However, if a team requests to print an excessive amount of code, the printing request may be denied.

## Important Notes

### Finals Registration

- A student ID or personal ID is required upon registration.
- To enter the contest venue, all 3 team members must register simultaneously.
  - If one or more team members are absent, entry will not be permitted.
- Entry is not permitted after the contest start time.
  - Registration may be delayed as it gets closer to the contest start time. If you do not arrive at least 30 minutes before the contest starts, entry may be difficult, and we are not responsible for any disadvantages caused by delayed registration.

### Team Reference Document

- You may bring a team reference document consisting of up to 25 single-sided A4 pages. You must print the team reference document yourselves and bring either 1 or 3 copies.
  - If the printed text is too small (<2mm, approx. 6pt), it may be rejected.
  - Team reference documents will be inspected during registration, and if rejected, they cannot be brought in.
- All pages of the team reference document must have the team name and page number printed on them.

### Reference Documents

The following language-specific reference documents can be accessed and used during the contest.

- C/C++: [https://en.cppreference.com/w/](https://en.cppreference.com/w/)
- Java: [https://docs.oracle.com/en/java/javase/index.html](https://docs.oracle.com/en/java/javase/index.html)
- Kotlin: [https://kotlinlang.org/docs/home.html](https://kotlinlang.org/docs/home.html)
- Python: [https://docs.python.org/3/](https://docs.python.org/3/)

### Allowed Programming Tools

- Code used for solving problems must be written during the contest time.
  - Typing code from the team note or copying/pasting code from the reference documents above is allowed.
  - Code formatters are allowed only if they do not change the content of the code and only modify whitespace, etc.
  - Pre-written code related to algorithmic problem solving, such as [Atcoder Library](https://github.com/atcoder/ac-library), cannot be used. This is not limited to the submitted code and includes code written for testing purposes.
  - Tools that generate code using simple grammar, such as [Lex & Yacc](http://dinosaur.compilertools.net/) or [cLay](http://rsujskf.s602.xrea.com/?cLay), cannot be used.
  - Template code written before the contest starts cannot be used. It is allowed if written after the contest begins.
- Autocompletion and code recommendation features are allowed if they are related to the contents of the official reference documents.
  - Extensions such as [IntelliSense](https://code.visualstudio.com/docs/editor/intellisense) in [Visual Studio Code](https://code.visualstudio.com/) and [Completions](https://www.sublimetext.com/docs/completions.html) in [Sublime Text](https://www.sublimetext.com/) can be used.
  - Programs like [Copilot](https://github.com/features/copilot) that use existing code cannot be used.
- Other tools not related to writing code (e.g., compiling using shortcut keys, input pipelines, simple code comparison like Unix's `diff`) can be used.
  - Extensions for Visual Studio Code, such as [Code Runner](https://marketplace.visualstudio.com/items?itemName=formulahendry.code-runner) and [Competitive Programming Helper](https://marketplace.visualstudio.com/items?itemName=DivyanshuAgrawal.competitive-programming-helper), can be used.
- For any other inquiries, please contact us via the contact information on the main page.

### During the Contest

- You must not communicate with anyone other than your teammates during the contest. Communicating about the problems in any form with a non-teammate is considered cheating.
- You must not share the contest account information with anyone who is not a teammate.
- Reference to any external documents or code, other than the team reference document and language references, is not permitted.
- Violating the above notes will be considered cheating and will result in disqualification, and any awards won may be revoked.
- Any other matters not explicitly stated herein may be decided at the discretion of the organizers.

### Other Matters

- Please use the question feature on the contest platform for any inquiries about the problems. Note that questions that are difficult to answer may receive a reply of "We cannot provide an answer" (No comments).

## Judging Environment

- It is guaranteed that all problems can be solved within the time limit and memory limit using at least one of the languages supported by the contest.

## Supported Languages

Following ICPC trends, only **C, C++, Java, Kotlin, and PyPy3** are available.
For language-specific environments and execution methods, please refer to the [BOJ Language Environment](https://www.acmicpc.net/help/language) page.

**No additional time or memory will be provided per language**.
Participants must choose an appropriate language for each problem.
